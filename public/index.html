¿Cómo participar?

Tres pasos simples para estar en la feria

1

Completá el formulario

Ingresá el nombre de tu emprendimiento, el rubro y el tipo de espacio que necesitás: tablón, perchero, o ambos.

2

Elegí las fechas

Seleccioná una o varias fechas disponibles. Cada feria muestra el lugar y el precio del espacio.

3

¡Confirmado!

Recibís la confirmación al instante con las recomendaciones para prepararte para el día de la feria.
